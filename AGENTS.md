# AGENTS.md

## English-only guard

All project changes MUST be written in English.

When creating or editing any file in this repository -- source code, README, documentation, templates, tests, comments, or config examples -- write all content in English. Generate commit messages in English too.

Rules:

- Code: strings, identifiers, comments, and docstrings in English.
- Templates and user-visible labels: English.
- README and docs: English.
- Commits: English messages.
- Chat replies in the user's language are fine; this rule governs repository artifacts only.
- Do not migrate pre-existing non-English content unless explicitly asked; only new/edited content must be English.

Load and follow the `enforce-english` skill for the detailed rules and self-check checklist.
